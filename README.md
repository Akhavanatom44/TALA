# 🤖 ربات هوشمند بازنشر فری‌فایر و قیمت طلا (نسخه Next.js / Docker)

ربات تلگرامی کامل برای رصد خودکار کانال‌های منبع، تحلیل محتوا با **Gemini AI**، بازنویسی ضدکپی، حذف
لینک/آیدی کانال‌های دیگر، و انتشار خودکار در کانال‌های شما (فری‌فایر و قیمت طلا) همراه با **پنل مدیریت کامل**.

> این پروژه دو پیاده‌سازی کاملاً مستقل دارد: همین نسخه (Next.js + Docker) و یک نسخه مستقل Python
> (aiogram + FastAPI). هرکدام را جدا می‌توانید دیپلوی کنید.

## ✨ امکانات

- رصد لحظه‌ای هر تعداد کانال منبع از طریق Webhook تلگرام (بدون نیاز به polling/کرون)
- تحلیل هوشمند هر پست با Gemini API برای تشخیص مرتبط بودن با موضوع کانال
- بازنویسی خودکار متن (ضدکپی) + حذف کامل لینک/یوزرنیم/دعوت به کانال‌های دیگر
- پشتیبانی از پست‌های تک‌عکس، تک‌ویدیو و آلبوم (چند عکس/ویدیو با هم)
- فوتر اختصاصی قابل تنظیم (متن + دکمه شیشه‌ای لینک‌دار) برای هر کانال مقصد
- دو ماژول کاملاً مجزا: کانال فری‌فایر و کانال قیمت طلا (هرکدام کانال‌های منبع/مقصد/پرامپت جدا)
- حالت «تایید دستی» پیش از انتشار (در صورت نیاز)
- فیلتر کلمات ممنوعه + محدودیت حداقل فاصله زمانی بین پست‌ها (ضد فلود)
- پنل مدیریت کامل تحت وب: تنظیمات، کانال‌ها، گزارش‌ها، تست اتصال و تست ارسال
- جدول گزارش کامل (Audit Log) با وضعیت هر پست (منتشرشده/نامرتبط/خطا/در انتظار)

## 🚀 دیپلوی با Docker (پیشنهادی)

```bash
cp .env.example .env
# مقادیر ADMIN_PASSWORD و AUTH_SECRET را تغییر دهید
docker compose up -d --build
```

سپس به آدرس سرور خود مراجعه کنید، وارد `/admin` شوید و از صفحه تنظیمات:

1. توکن ربات تلگرام (از @BotFather) و آدرس عمومی سایت را وارد و ذخیره کنید.
2. کلید Gemini API را وارد کنید (از https://aistudio.google.com/app/apikey).
3. روی «فعال‌سازی وب‌هوک» بزنید.
4. ربات را به‌عنوان **ادمین** در کانال‌های منبع مورد نظر اضافه کنید.
5. از صفحه «کانال‌های فری‌فایر» / «کانال‌های قیمت طلا» کانال مقصد و فوتر را تنظیم کنید.

## 🧑‍💻 اجرای توسعه (بدون Docker)

```bash
npm install
npx drizzle-kit push
npm run dev
```

## 🔑 متغیرهای محیطی

| متغیر | توضیح |
|---|---|
| `DATABASE_URL` | آدرس اتصال PostgreSQL |
| `ADMIN_PASSWORD` | رمز عبور ورود به پنل مدیریت |
| `AUTH_SECRET` | رشته محرمانه برای امضای کوکی نشست ادمین |

> توکن ربات تلگرام، کلید Gemini، کانال‌ها و فوترها همگی از **داخل پنل مدیریت** تنظیم می‌شوند؛ نیازی به
> ویرایش فایل env برای این موارد نیست.

## 🏗️ معماری

- `src/db/schema.ts` — مدل‌های Drizzle (تنظیمات، کانال‌های منبع/مقصد، گزارش پست‌ها)
- `src/lib/telegram.ts` — کلاینت سبک Bot API تلگرام
- `src/lib/gemini.ts` — ارتباط با Gemini API برای تحلیل/بازنویسی متن
- `src/lib/sanitize.ts` — پاک‌سازی لینک/آیدی/کلمات ممنوعه
- `src/lib/bot/engine.ts` — موتور اصلی پردازش پست‌ها (شامل بافر آلبوم، دی‌دوپ، انتشار)
- `src/app/api/telegram/webhook/route.ts` — ورودی webhook تلگرام
- `src/app/admin/**` — پنل مدیریت کامل

## ⚠️ نکته مهم درباره عملکرد ربات

تلگرام فقط زمانی پست‌های یک کانال را برای ربات ارسال می‌کند که ربات **ادمین** آن کانال باشد. به محض
افزودن ربات به‌عنوان ادمین و ثبت کانال در پنل، تمام پست‌های بعدی آن کانال به‌صورت خودکار بررسی می‌شوند —
نیازی به دسترسی به تاریخچه قدیمی کانال نیست و دقیقاً مطابق نیاز «از این لحظه به بعد» عمل می‌کند.
